## 每篇写作要点（对应队列 JSON 已填好的选题卡）

### P0-a pet-memorial-gifts（骨架已在 content/drafts/）
- 补 description（50-160 字符含主词）、cover（建议 `/tpl/baroque.jpg` 古典庄重）、tags。
- 语气红线：安静温柔、无感叹号堆叠、CTA 只出现一次；引用 pet loss support 资源。
- 加真实问候语/墓志铭范例段落（"What to write" 一节是 PAA 抓手）。

### P0-b ai-vs-traditional-pet-portrait
- 核心资产是**对比表**：价格（$0-30 / $50-300 / $300+）、交付（30 秒 / 1-2 周 / 4-8 周）、修改次数、商用授权。
- 价格区间需抽查 3 个 Etsy/画家报价作引用源；自身定价用 `/pricing` 真实数字。
- 结论按人群分流：想快速多试 → AI；收藏级原件 → 手绘；预算中间 → AI 高清打印装裱。

### P1-a unique-cat-names
- 300+ 名字按主题分组（文艺/食物/神话/影视/毛色），每条带一句含义——这是与竞品 50 词列表拉开差距的量。
- 内链 cat-names 工具（"按性别/风格筛选+收藏"），与 dog-names 工具互文。
- 长尾覆盖 male/female/black cat/orange cat 变体（H2 分组天然承接）。

### P1-b dog-years-to-human-years
- **健康话题：必须引用 Cornell/VCA/AVMA 的年龄换算研究**（如 AVMA 的 1 岁=15 人类年算法与体型修正表），标注"更新于 2026-10"。
- 数据结构：对照表（小型/中型/大型犬三列）+ 猫的简表；内嵌 pet-age 工具链接（"懒得查表？输入生日直接算"）。
- 一手信号：用我们工具的真实换算数字截图/示例 2 个。

### P1-c gifts-for-dog-moms（季节，≤11 月中）
- 纯商业意图：10-15 件礼物按预算分档（<$25 / $25-75 / $75+），每件注明"个性化程度/交付时长"。
- AI 写真礼物放 $25-75 档（免费生成 + Pro 无水印下载装裱），对比定制手绘的性价比。
- title/description 带 "2026" 提升点击率；12 月初可加圣诞礼物段并 refresh。

### P2-a funny-cat-meme-captions
- 复制狗版已验证格式：101 条按心情分组（瞧不起人类/深夜跑酷/纸箱霸权/干饭狂魔）。
- 与狗版互链（"dog person? → 101 dog captions"），meme maker CTA 同款。

### P2-b dog-birthday-ideas
- 时间线结构：前 1 周准备 → 当天流程 → 拍照清单 → 纪念方式（生成一张生日写真）。
- 安全断言（狗能吃什么蛋糕）引用 AKC；cover 用 `/tpl/birthday.jpg`。

### P3 valentine-cards-with-your-pet（≤12 月底发布）
- 单人+宠 / 情侣+宠 / "pet is my valentine" 三种场景 × 8-10 个创意。
- 情人节模板若站内没有，先在 templates 加 2-3 个（rose/pink 系提示词），文章与模板互相导流。

## 执行方式（每篇走 SOP ④⑤⑥）

```
npm run blog:scaffold -- --id=<选题id>   # 生成骨架到 content/drafts/
# 填充内容（persona 语气 + ≥600 词 + ≥3 H2 + ≥2 图 + 内链槽位填满）
npm run blog:lint                        # 门禁：0 error 才算过
# 移入 src/content/blog/ → build 自动进 sitemap → GSC 提交 → 社媒分发
```

每批完成的验收：`blog:lint` 0 error + 人工复核清单（SOP ⑤）全过 + 主关键词五点落位抽查。
